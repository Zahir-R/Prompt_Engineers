# Microcopy en español

## Voz

- Cercana, clara y tranquila.
- "Tú" para estudiantes.
- Respetuosa y profesional para docentes.
- Sin culpa: "todavía no", "revisemos juntos".

## Reglas rápidas

- Acentos y signos de apertura.
- Frases cortas.
- Nombres concretos.
- Una idea por oración.
- Nada de tecnicismos sin explicación.

## Ejemplos

| Evitar | Preferir |
| :--- | :--- |
| Incorrecto | Todavía no es la respuesta. Revisa y vuelve a intentarlo. |
| Fallaste | No pasa nada, los errores ayudan a aprender. |
| OK | Comprobar |
| Continuar | Siguiente |
| Ver solución | Ver Modo Desglose |

## Contexto

Usar referencias cotidianas y diversas, sin estereotipos. Mantener el español
boliviano neutro y comprensible.
