# Usuarios

## Estudiante (6–13 años)

Hipótesis de trabajo:

- Sesiones cortas de 2–4 minutos.
- Necesita una tarea visible por pantalla.
- Aprende con ejemplos concretos y repetición variada.
- Puede frustrarse con texto largo o mensajes culpabilizantes.
- Usa principalmente móvil o tablet.
- Necesita botones grandes y foco claro.

## Docente / tutor

- Quiere crear ejercicios sin programar.
- Necesita ver una vista previa antes de guardar.
- Quiere un resumen simple del avance.
- No necesita datos sensibles del menor.

## Restricciones

- No se ingresan datos de menores.
- Estudiantes usan alias y avatar; sin correo ni nombre real.
- El docente trabaja en backstage.
- No se usa LLM dentro del producto.

## Validación pendiente

- 3–5 entrevistas breves con docentes.
- Prueba de usabilidad con 2–3 niños.
- Observar dónde se pierde la atención y qué texto no se entiende.
