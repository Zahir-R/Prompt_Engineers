# Carpeta de referencias visuales

Guardar capturas con este formato:

```text
YYYY-MM-DD-fuente-pantalla.png
```

Cada imagen debe estar descrita en
`docs/research/03-referencias-visuales.md` con:

- Fuente.
- Qué funciona.
- Qué evitar.
- Patrón aplicable.

No guardar capturas sin fuente ni imágenes generadas por IA sin dirección de
arte.
