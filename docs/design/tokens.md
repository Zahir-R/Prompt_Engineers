# Tokens visuales

## Color

| Token | Valor | Uso |
| :--- | :--- | :--- |
| `paper` | `#fbf6ea` | Fondo principal de fichas |
| `paper-deep` | `#efe2c8` | Zonas secundarias |
| `ink` | `#2c2733` | Texto, bordes y sombras |
| `ink-soft` | `#5b5264` | Texto secundario |
| `coral` | `#e26352` | Acentos y energía |
| `coral-deep` | `#b83f30` | Acción principal |
| `mustard` | `#e8a73a` | Pistas y énfasis |
| `teal` | `#24887b` | Progreso y logros |
| `sky` | `#3c77b4` | Enlaces y foco |
| `plum` | `#7052a3` | Respuesta final |
| `blue`, `orange`, `green`, `purple`, `yellow` | Tailwind | Solo Modo Desglose |

El fondo del body usa papel `#f5ecd9` con una retícula de puntos sutil.

## Tipografía

| Token | Fuente | Uso |
| :--- | :--- | :--- |
| `font-display` | Fredoka | Títulos y números grandes |
| `font-sans` | Nunito | Texto de lectura |
| `font-hand` | Caveat | Notas, flechas y anotaciones |

## Forma

- Radio irregular: `1.25rem 0.8rem 1.5rem 1rem`.
- Borde: 2 px de tinta.
- Sombra dura: `4px 4px 0 rgba(44,39,51,0.18)`.
- Sombra fuerte: `6px 6px 0 #2c2733`.
- Rotaciones decorativas: `-2deg` a `2deg`.

## Espaciado

- Base: 4 px.
- Secciones: 24–40 px.
- Botones: alto mínimo 44 px.
- Inputs: alto mínimo 48 px.

## Movimiento

- Duración: 150–300 ms.
- Sin animaciones infinitas.
- Respetar `prefers-reduced-motion`.

## Utilidades propias

- `.paper-card`
- `.paper-card-strong`
- `.paper-note`
- `.tape`
- `.dotted-line`
